# Project Decisions

This file records finalized decisions that will affect future work in HomeLab Deck Web.

| Date | Decision | Rationale | Status | Affected Areas |
|---|---|---|---|---|
| 2026-09-27 | Integrated Project Memory System | Improve agent context efficiency and lower token usage | active | Root documentation & context |
| 2026-09-27 | Use Tailwind CSS v4 & Next.js 16 | Modern styling & latest React 19 App Router standard | active | UI & styling |
| 2026-09-27 | Site forced to light theme only; removed all `dark:` Tailwind variants and the `prefers-color-scheme: dark` CSS override | Starting baseline is light-only; a dedicated toggle can reintroduce dark mode later if needed | active | `globals.css`, `src/app/[locale]/page.tsx`, `apps/page.tsx`, `apps/[slug]/page.tsx` |
| 2026-10-03 | Dropped Nextcloud from the catalog (removed `src/content/apps/nextcloud.json`) | Nextcloud cannot be installed in an LXC container in the user's homelab, so real Proof-of-Work screenshots cannot be produced; entries without proof contradict the site's core value | active | `src/content/apps/` |
| 2026-10-10 | Added the `ai-audio` category (AI & Audio) and the Applio entry (voice conversion, RVC-based). Its compose snippet pins `torchvision==0.26.0` and `pedalboard==0.9.16` after tests on the homelab (upstream Dockerfile is out of date) | Catalog had no AI category; snippet was build-tested and served HTTP 200 with CUDA before publishing | active | `src/lib/apps/categories.ts`, `src/content/apps/applio.json` |
| 2026-10-10 | Reintroduced dark mode: `ThemeToggle` (sun/moon, localStorage `theme`, falls back to system preference) replaced the EN/BG `LocaleSwitcher` in the navbar at the user's explicit request; `dark:` variants via class-based `@custom-variant`. Locales stay reachable by URL (/en, /bg) | User asked to rework the language switcher into a light/dark toggle; supersedes the 2026-09-27 light-only decision | active | `ThemeToggle.tsx`, `Navbar.tsx`, `globals.css`, `layout.tsx` |
| 2026-10-10 | Added weekly notes: `src/content/weekly/<year>-w<NN>.json` (EN/BG text + app slugs), pages `/updates` and `/updates/[slug]` (Article JSON-LD, in sitemap), navbar link, home "Latest content" shows the newest note with app cards. Home stats row replaced by a placeholder subscribe form; hero "Browse apps" button removed | SEO text content that grows weekly; per user request | active | `src/lib/weekly.ts`, `src/app/[locale]/updates/`, `src/content/weekly/` |
| 2026-10-10 | Added `/guides` and `/guides/[slug]` (content in `src/content/guides/<slug>.json`, EN+BG, comparison table pulls RAM/license/tagline from the app catalog, Article JSON-LD, sitemap, home "Guides" section). First guide: `self-hosted-alternatives-to-saas` | SEO long-form content; user asked for it as a new `/en/guides` page | active | `src/lib/guides.ts`, `src/app/[locale]/guides/`, `src/content/guides/` |
| 2026-10-10 | Typography: font is Inter (`next/font`, subsets latin+cyrillic, `--font-inter`, sans-serif fallback) site-wide, replacing Geist/Arial. `font-semibold` removed from all headings (h1–h3; navbar logo kept). Hero h1 classes: `max-w-[1080px] font-medium tracking-tight text-balance text-3xl sm:text-4xl md:text-5xl md:font-normal lg:text-6xl xl:text-7xl` (72px from xl); hero section `max-w-[1080px]` centered | User's explicit design request | active | `layout.tsx`, `globals.css`, `page.tsx`, all heading pages |
| 2026-10-18 | Newsletter built in-house, not via a third-party list service: form → `/api/subscribe` (double opt-in, honeypot, rate limit), subscribers in Redis (`REDIS_URL`), mail from `news@homelabdeck.dev` via Resend (free plan, 100/day, 80 used by newsletter). Issues are files in `src/content/newsletter/*.json` (`sendAt`, EN/BG subject+HTML); a daily Vercel cron (`/api/cron/newsletter`, auth `CRON_SECRET`) sends due issues. Buttondown was tried and dropped (owner's personal name shown, no own-domain sending) | Sender identity must be HomelabDeck on the project's own domain; free tools only | active | `src/lib/newsletter.ts`, `src/app/api/`, `vercel.json`, `src/content/newsletter/` |
| 2026-10-18 | Added footer (Apps, Guides, Updates, Newsletter), subscribe invitation at the end of each guide, and a left off-canvas side panel (nav + category links; apps list filters via `?category=`). Panel renders in a portal because the header's `backdrop-blur` would otherwise confine `fixed` children. User wants a design revision of the panel later | Discoverability of guides/newsletter; filtering for a growing catalog | active | `Footer.tsx`, `SidePanel.tsx`, `AppsList.tsx`, `SubscribeForm.tsx` |
| 2026-10-22 | No new Bulgarian (BG) translations for new content (apps, guides, weekly notes, newsletter). Existing BG pages and `/bg` URLs stay live and unchanged (add-only rule); a Turkish locale was considered and postponed | Search Console (Oct 6–20) shows an English-speaking audience (US, CA, DE, UK); BG gives ~2 impressions; translation upkeep is not worth it. New content is EN-only until the user says otherwise | active | `src/content/`, `messages/`, `src/lib/apps/schema.ts` |
| 2026-10-22 | Added the Homepage entry (category `monitoring`) and made `descriptionBg`, `taglineBg` and screenshot `altBg` optional on apps, falling back to English; added optional `seoTitle*`/`seoDescription*` overrides. Homepage screenshots come from a separate demo instance with a curated config (no real IPs/hostnames) | Implements the no-new-BG decision of 2026-10-22; nicer screenshots without exposing the live dashboard | active | `src/lib/apps/schema.ts`, `src/app/[locale]/apps/`, `src/content/apps/homepage.json`, `public/screenshots/homepage/` |
| 2026-10-22 | Added the ComfyUI entry and the `ai-image` category (AI Images & Video). The deployment block is our real systemd unit (no official Docker image), screenshots are the real UI after an SDXL run plus a terminal capture | Catalog had no image-generation category; run measured on the homelab (RealVisXL, ~8 s per image, ~7 GB VRAM) | active | `src/lib/apps/categories.ts`, `src/content/apps/comfyui.json`, `public/screenshots/comfyui/` |
