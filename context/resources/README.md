# Resource System

This folder stores raw resources provided by the user or project upon which the project context rests.

## Folders

| Location | Contents |
|---|---|
| `documents/` | PDF, Word, presentation, and text documents |
| `data/` | Excel, CSV, JSON, and other structured data |
| `images/` | Screenshots, charts, photos, and drawings |
| `audio-and-video/` | Audio recordings, meeting recordings, and videos |
| `links.md` | Web pages and online resources |
| `resource-index.md` | Log and description list of all actual resources |
